# 🎮 Jogo da Forca

## 📌 Sobre o projeto

O Jogo da Forca é um projeto desenvolvido em grupo, utilizando HTML, CSS e JavaScript, com o objetivo de criar um jogo interativo e divertido, colocando em prática conhecimentos de desenvolvimento web.

O jogo consiste em descobrir uma palavra secreta por meio de tentativas de adivinhar suas letras. A cada erro, o jogador se aproxima de completar o desenho da forca.

## 🎯 Objetivo do projeto

Desenvolver um jogo da forca funcional e intuitivo, utilizando tecnologias de desenvolvimento web, aprimorando os conhecimentos em programação, criatividade e trabalho em equipe.

## 🕹️ Como jogar?

1. O sistema seleciona uma palavra secreta.
2. O jogador deve escolher uma letra por tentativa.
3. Caso a letra esteja correta, ela será revelada na palavra.
4. Caso esteja errada, será contabilizada uma tentativa perdida.
5. O jogador vence ao descobrir todas as letras da palavra.
6. O jogador perde quando todas as tentativas disponíveis acabam.

## 💻 Tecnologias utilizadas

- **HTML5:** responsável pela estrutura da página.
- **CSS3:** responsável pela estilização e aparência visual do jogo.
- **JavaScript:** responsável pela lógica, funcionalidades e interatividade do jogo.
