Como jogar Forca

Descubra a palavra secreta antes de completar o desenho da forca.

  1. Escolha uma categoriaUse o seletor para escolher um tema ou jogar com todas as palavras.
  2. Chute uma letraDigite uma letra ou use o teclado na tela. Letras acentuadas também são aceitas.
  3. Acompanhe seus errosCada erro custa uma vida. Você tem seis tentativas; revelar uma letra também custa uma vida.
  4. Descubra a palavraAcerte todas as letras antes de ficar sem vidas para vencer a rodada.
